# 🏏 DSA Premier League

An interactive, IPL-themed web game designed for learning and practicing Data Structures & Algorithms (DSA) through animated cricket match experiences.

## 🌟 Features
- **Animated Cricket Stadium Experience**: Persistent stadium backdrop with floating light particles, floodlights, dynamic boundary rope, and score popups.
- **8 IPL Teams**: Choose from customized teams (Chennai Kings, Bengaluru Strikers, Mumbai Mariners, Kolkata Warriors, Punjab Lions, Rajasthan Rovers, Delhi Defenders, Hyderabad Blazers).
- **Game Engine & Cricket Scoring**:
  - **SIX (6)**: Answer correct in the first 35% of timer.
  - **FOUR (4)**: Answer correct in the first 65% of timer.
  - **1–3 RUNS**: Answer correct in remaining time.
  - **OUT (WICKET)**: 5 consecutive wrong/missed deliveries.
- **Game Modes**: Practice Match, IPL Showoff (2–8 players), Team Battle, and Custom Sheet support.
- **Question Bank**: 70+ verified DSA questions across 12 CS categories (Arrays, Linked Lists, Trees, Graphs, Dynamic Programming, etc.).

## 🚀 How to Run
Open `index.html` directly in your browser or serve using Python:

```bash
python -m http.server 8765
```
Then visit `http://localhost:8765` in your browser.
