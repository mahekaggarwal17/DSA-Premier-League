> An interactive, IPL-themed web game designed for learning and practicing Data Structures & Algorithms (DSA) through animated cricket match experiences — **generated and engineered with OpenAI Codex**.

---

## 🌟 Features
- **Animated Cricket Stadium Experience**: Persistent 3D-style stadium backdrop with floating light particles, floodlights, dynamic boundary rope, and score popups.
- **8 Blended IPL Teams**: Choose from customized teams (Chennai Kings, Bengaluru Strikers, Mumbai Mariners, Kolkata Warriors, Punjab Lions, Rajasthan Rovers, Delhi Defenders, Hyderabad Blazers).
- **Codex-Engineered Scoring Rules**:
  - **SIX (6 Runs)**: Correct answer submitted in the first 35% of the delivery timer.
  - **FOUR (4 Runs)**: Correct answer submitted in the first 65% of the delivery timer.
  - **1–3 RUNS**: Correct answer submitted in the remaining time window.
  - **OUT (WICKET)**: Triggered after 5 consecutive wrong or missed deliveries.
- **Game Modes**: Solo Practice Match, local pass-and-play IPL Showoff (2–8 players), Team Battle mode, and custom JSON/CSV question-sheet loading.
- **DSA Question Bank**: 70+ verified Data Structures & Algorithms questions spanning 12 core computer science categories (Arrays, Trees, Graphs, DP, Sorting, etc.).

## 🚀 Getting Started

### Direct Launch
Open `index.html` directly in any modern web browser (Chrome, Firefox, Edge, Safari).

### Local Server
Run a simple HTTP server using Python:

```bash
python -m http.server 8765
```

Navigate to `http://localhost:8765` in your browser.
