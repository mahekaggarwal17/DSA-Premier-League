# OpenAI Codex Project Specification & Instructions

This repository contains the source code for **DSA Premier League**, engineered with assistance from **OpenAI Codex**.

## ⚙️ Codex Environment Rules & Standards

### 1. Code Architecture
- Use strict JavaScript ES6+ features (arrow functions, template literals, destructuring, modules where applicable).
- Keep code clean, self-documenting, and free of heavy external dependencies.
- Ensure all DOM manipulations use explicit selectors and guard clauses.

### 2. Styling Guidelines
- Theme: Ultra-modern dark glassmorphism stadium interface.
- Use CSS variables for design tokens (colors, typography, spacing, shadows).
- Ensure animations use `transform` and `opacity` for 60 FPS GPU hardware acceleration.

### 3. Game Engine Standards
- Data-driven question loading from `js/questions.js` and `js/coding_problems.js`.
- Responsive event handling for practice, multiplayer, and custom JSON sheets.
